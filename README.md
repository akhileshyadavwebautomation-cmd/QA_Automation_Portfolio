## 🚀 Featured Automation Projects

### 1. Playwright E-commerce Automation

**Technologies:** Playwright, TypeScript, Node.js

**Repository Folder:** `01-playwright-ecommerce`

**Key Features:**
- Page Object Model (POM) architecture
- Reusable page classes and test utilities
- Login and authentication testing
- Product search and validation
- Shopping cart and checkout scenarios
- Playwright HTML reporting
- GitHub Actions CI workflow

**Execution Commands:**

```bash
cd 01-playwright-ecommerce
npm install
npx playwright install
npm test
```

### 2. Selenium Web UI Automation

**Technologies:** Java, Selenium WebDriver, TestNG, Maven

**Repository Folder:** `02-selenium-web-ui`

**Key Features:**
- Selenium WebDriver automation
- Page Object Model implementation
- TestNG test execution
- Maven dependency management
- Reusable automation components
- Extent Reports

**Execution Command:**

```bash
cd 02-selenium-web-ui
mvn clean test
```

### 3. REST API Automation

**Key Features:**

- API response validation
- JSON schema validation

- TestNG execution

**Execution Command:**
